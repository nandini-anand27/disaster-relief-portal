# Contributing to Bengaluru Civil Relief Network

Thank you for contributing to emergency disaster response tools!

## How to Contribute
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/BBMP-Zone-Update`).
3. Commit your changes (`git commit -m 'Add Yelahanka zone shelters'`).
4. Push to the branch (`git push origin feature/BBMP-Zone-Update`).
5. Open a Pull Request.

## Guidelines
- Ensure all features remain zero-dependency (Vanilla JS/CSS only).
- Test offline queue functionality under simulated 2G conditions.
